개인 투자 대시보드

코인·국내주식·해외 지수를 한 화면에서 보는 1인용 로컬 웹 콘솔

무엇을 만들었나

업비트(코인)와 한국투자증권(국내주식) API, 해외 지수/ETF 시세를 묶어 한 화면에서 보유 현황과 지표를 보는 개인용 웹 콘솔입니다.

주요 기능

  • 보유 자산 평가, 기간별 변동, 지수 대비 수익 비교, 손익 기여도
  • 매일 알림·장중 감시 (텔레그램)
  • 주문은 텔레그램 승인을 거쳐야만 실행되고, 1회·하루 한도와 킬스위치를 둠

설계에서 신경 쓴 점

  • 비밀값은 레포 밖에만 두고, 커밋·푸시 전에 실제 키 값과 비밀 패턴을 검사하는 훅을 연결
  • 외부 노출 없이 127.0.0.1 + 사설 VPN 으로만 접근
  • 기능마다 조사 → 계획 → 구현 → 검증 → 회고 문서를 남기며 진행
