## 무엇을 만들었나
지원 업계를 등록하면 현직자·채용 담당자·자소서 코치 세 관점의 에이전트가 자기소개서를 검토하고, 편집장 에이전트가 키워드와 수정 요청을 반영해 다시 써 주는 웹앱입니다. 기업 조사, 모의 면접, 경력기술서 평가 기능도 있습니다.

## 설계에서 신경 쓴 점
- 역할별로 모델을 나눠 비용을 통제 (검토는 작은 모델, 최종 수정은 큰 모델). 호출마다 토큰·비용을 로그로 남겨 실측
- Google 로그인 + 허용 이메일 목록, 계정별 일일 한도
- Google Cloud Run(서울 리전)에 배포해 요청이 없을 때 인스턴스 0 → 소규모 사용은 무료 범위

**Stack** Python · Claude API · Firestore · Cloud Run
